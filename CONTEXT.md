# Context

## Glossary

### Facebook Post

A Facebook Post is organic Page content generated by the agent from a user's post idea. It contains one realistic image, one caption, and hashtags.

### Post Preview

A Post Preview is the approval checkpoint shown before publishing. The user can approve it or ask to regenerate the image, caption, hashtags, or all post content.

### Regeneration Scope

Regeneration Scope identifies which part of a rejected Post Preview should change: image, caption, hashtags, or all. Parts outside the selected scope must be preserved.

### Connected Facebook Page

A Connected Facebook Page is the Page available through the user's Meta connection and Page publishing permissions. Approved Facebook Posts are published there.

### Published Post

A Published Post is a Facebook Post that has passed approval and has been sent to Facebook as a Page photo post.

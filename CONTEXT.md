# Context

## Glossary

### Facebook Post

A Facebook Post is organic Page content generated by the agent from a user's post idea. It contains one generated media asset, one caption, and hashtags.

### Generated Post Media

Generated Post Media is the realistic visual asset attached to a Facebook Post. It can be either a realistic image or a realistic short video.

### Post Preview

A Post Preview is the approval checkpoint shown before publishing. The user can approve it or ask to regenerate the media, caption, hashtags, or all post content.

### Regeneration Scope

Regeneration Scope identifies which part of a rejected Post Preview should change: media, caption, hashtags, or all. Parts outside the selected scope must be preserved.

### Post Language

Post Language is the language detected from the user's original Facebook Post request. Captions, hashtags, image prompts, and regenerated post content stay in this language for the life of that Post Preview.
Video prompts follow the same language rule.

### Reply Language

Reply Language is the language detected from the user's latest chat message. Agent conversational replies use this language even when the Post Language remains unchanged.

### Connected Facebook Page

A Connected Facebook Page is the Page available through the user's Meta connection and Page publishing permissions. Approved Facebook Posts are published there.

### Published Post

A Published Post is a Facebook Post that has passed approval and has been sent to Facebook as a Page photo post.
